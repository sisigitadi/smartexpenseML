Bagaimana Machine Learning Ini Bekerja?

100% Client-Side & Zero API

Aplikasi ini tidak mengirimkan data apapun ke server luar atau menggunakan API berbayar. Seluruh pemrosesan teks, komputasi ML, dan penyimpanan data dilakukan langsung di browser Anda.

1. RegEx Natural Language Parser (NLP)

Mndeteksi pola angka Indonesia/Inggris secara fleksibel seperti 15rb, 20k, 2.5jt, 100ribu, $50 dan memisahkannya dari kata deskripsi barang.

2. Naive Bayes & Keyword Classifier

Setiap kata yang dipisah (tokenized) dihitung nilai probabilitasnya terhadap masing-masing kategori (seperti Makanan, Transportasi, Tagihan, dsb).

3. Active Online Learning (Pembelajaran Interaktif)

Ketika Anda memperbaiki kategori transaksi di tabel riwayat, model ML secara otomatis menambahkan bobot kata tersebut ke dalam memori lokal (localStorage) sehingga deteksi berikutnya menjadi semakin cerdas!
